For web development, the public docs describe:

- Desktop browser previews: start a dev server, open its local URL, inspect it and leave visual feedback. They explicitly use localhost examples. [Browser docs](https://learn.chatgpt.com/docs/browser#preview-a-page)
- Sites: build, preview and publish web apps through the managed Sites workflow. That doesn’t establish support for IWAs. [Sites docs](https://learn.chatgpt.com/docs/sites)
- Connected computers or configured Codex cloud environments: run development work in those environments. [Computer docs](https://learn.chatgpt.com/docs/dots/computers-and-apps)

The cloud-computer docs also explicitly say it supports software work. What I haven’t found is a documented working local-preview route for this particular cloud setup. The desktop localhost instructions don’t explain the block we’re seeing here
