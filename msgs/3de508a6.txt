I discovered samsung doing similar years ago along with a bug where you could take over any tv on the network from a web page loaded in a browser on the same network. They would post all your info to an api that aggregated it based on your gateway ip and if you came from same gateway ip you could read it back. That combined with dev mode that could be enabled remotely over network and was only protected by a captcha that was easily passed using js ocr was all that stopped any random web page from owning the tv. When I tried reporting it to the team responsible for the TV software asked me not to send it to the responsible disclosure address as they were not sure that was actually samsung. 🙂
